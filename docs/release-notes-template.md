# Release notes template

The closing lines of every GitHub release's notes, after the release's own
paragraphs. Replace X.Y.Z.

```markdown
Capsid X.Y.Z needs macOS 27.

**First launch.** Capsid isn't notarized by Apple, so if you download Bench.zip
through a browser, macOS blocks it the first time. Open it once, click
**Done**, then go to **System Settings → Privacy & Security**, scroll down to
**Security**, click **Open Anyway** next to Capsid and confirm. Right-click →
Open no longer gets past this on current macOS. Installing or updating with
the [one-line install](https://github.com/samporter14/bench#easiest-one-line-in-terminal),
or with Capsid's own **Install and Reopen**, skips this step.
```
