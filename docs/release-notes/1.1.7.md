**Capsid 1.1.7: Claude Science 0.1.73's new approval cards, and safer folder saves.**

**Saving into your folders.** Claude Science 0.1.73 asks before Claude's code saves a file into a folder you gave it Read & write access to. Capsid now says "Wants to save a file into your folder" for these, and your phone shows which file. They're answered in Claude Science on your Mac, where you can read the file first.

**Saved keys.** When code would use a saved key (an OpenAlex key or a GitHub token, say), Claude Science 0.1.73 checks with you first, even with auto mode on. Capsid says "Wants your OK to use a saved key. Skipped after 10 minutes", because Claude Science gives up on it after 10 minutes if nobody's looking. From your phone or a card you can deny it, but allowing it needs your Mac, where you can see why it was held.

**Code auto mode held.** Code that auto mode held for review can no longer be allowed from your phone or a card, only denied. Why it was held is shown in Claude Science.

**Clearer waiting reasons.** A session waiting to run code now says "Wants to run code", and one waiting to use a saved credential says "Wants to use a saved key", instead of "Waiting for you".

**Save All.** Files that programs open by themselves when you work in a folder (like `.Rprofile`, `CLAUDE.md` or `nextflow.config`) are saved with `_` in front, as Claude Science 0.1.73 does for its zip downloads, and a `renamed_files.txt` lists them. Save and drag keep the original names.

**Diagnostics** now says Capsid was checked with Claude Science 0.1.73.

Capsid 1.1.7 needs macOS 27.

**First launch.** Capsid isn't notarized by Apple, so if you download Bench.zip
through a browser, macOS blocks it the first time. Open it once, click
**Done**, then go to **System Settings → Privacy & Security**, scroll down to
**Security**, click **Open Anyway** next to Capsid and confirm. Right-click →
Open no longer gets past this on current macOS. Installing or updating with
the [one-line install](https://github.com/samporter14/bench#easiest-one-line-in-terminal),
or with Capsid's own **Install and Reopen**, skips this step.
